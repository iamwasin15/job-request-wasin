อัปเดตข้อมูล

กำลังโหลดข้อมูลเดิม…

วิธีใช้

  1. เลือกไฟล์ CSV ที่ส่งออกจาก Excel (เลือกหลายไฟล์พร้อมกันได้ ชื่อไฟล์ควรมีเดือน เช่น All-Work-2026(Nov-2026).csv)
  2. ตรวจสรุปด้านล่างว่าเพิ่ม/เปลี่ยนตรงกับที่คาดไหน
  3. กด “ดาวน์โหลด data.js”
  4. ไปที่ GitHub แล้วอัปโหลด data.js ทับไฟล์เดิม (ไฟล์เดียวพอ) รอ 1-2 นาทีแล้วเปิดหน้าเว็บตรวจ

หน้านี้ยังไม่แก้เว็บจริงจนกว่าคุณจะอัปโหลดไฟล์ขึ้น GitHub

1. เลือกไฟล์ CSV

Ticket No ที่มีอยู่แล้วจะถูกอัปเดต ส่วน Ticket No ใหม่จะถูกเพิ่ม ระบบเก็บเฉพาะ Ticket No, Service Level, Vendor, Status และเดือน ส่วน Description, Latest Events, EndUser, Partner, PM, Engineer, Phone, Contract จะไม่ถูกเก็บในไฟล์ที่เผยแพร่

2. ตรวจสรุป

3. ดาวน์โหลด

ลบงาน (ถ้าจำเป็น)

ลบออกจากไฟล์ใหม่ที่กำลังจะดาวน์โหลด ยังไม่มีผลกับเว็บจริงจนกว่าจะอัปโหลด

โหลดข้อมูลเดิมจากเครื่อง

ถ้าเปิดหน้านี้จากไฟล์ในเครื่อง หรือระบบโหลดไม่ได้ ให้เลือกไฟล์ data.js ที่เคยดาวน์โหลดหรือโหลดมาจากเว็บ
